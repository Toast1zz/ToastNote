# ToastNote v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build ToastNote v1, a native, resource-light macOS Markdown notes app with a live-preview editor and BYOK AI formatting, as specified in the spec below.

**Architecture:** A SwiftUI app shell (`App/`) on top of a local Swift package `ToastNoteKit` with five library targets: VaultKit (files, watching, workspace state), EditorKit (Markdown parsing, styling, `MarkdownTextView` on TextKit 1), AIFormatKit (providers, protection, guard, block diff, pipeline), IndexKit (SQLite FTS5 tags and search), and ExportKit (Markdown → HTML → paginated PDF). All logic that can be tested without a window lives in the package; the App target is thin wiring plus views.

**Tech Stack:** Swift 6 (strict concurrency), SwiftUI + AppKit, TextKit 1, swift-markdown, Sparkle 2, system SQLite3, ImageIO, WebKit (export only), XcodeGen, Swift Testing, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-02-toastnote-design.md` — read it before starting any task. Section numbers below (e.g. "spec §7.3") refer to it. When this plan and the spec disagree, the spec wins; stop and report the conflict.

## How to run this plan

- Work milestone by milestone (M0 → M7). **At the end of each milestone, stop and hand the manual checklist to the user**; continue only after they confirm. Milestones are the natural session boundaries.
- Every task: TDD where a test is listed, then build, then commit. Never commit with failing tests.
- Standard commands (referred to below by name):
  - **TEST**: `swift test --package-path Packages/ToastNoteKit` (add `--filter <SuiteName>` to narrow)
  - **BUILD**: `xcodegen generate && xcodebuild -project ToastNote.xcodeproj -scheme ToastNote -configuration Debug -destination 'platform=macOS' build 2>&1 | tail -5` — expected last line contains `BUILD SUCCEEDED`
  - **RUN**: build with `-derivedDataPath build/DD`, then `open build/DD/Build/Products/Debug/ToastNote.app`.
- Commit messages: English, imperative, conventional prefix (`feat:`, `fix:`, `test:`, `chore:`, `docs:`), ending with the attribution line the harness provides.

## Global Constraints

- macOS deployment target **14.0**; Swift language mode **6**; strict concurrency on (spec §4.1).
- External dependencies: **only** `swift-markdown` (https://github.com/swiftlang/swift-markdown) and `Sparkle` (https://github.com/sparkle-project/Sparkle, 2.x). Anything else requires a spec change first (spec §3).
- **No App Sandbox**; Hardened Runtime on (spec §4.2).
- Bundle identifier: `app.toastnote.mac`. Keychain service: `app.toastnote.ai`, account = provider ID (spec §5.2).
- `.xcodeproj` is generated by XcodeGen and is git-ignored (spec §4.3).
- Tests use Swift Testing (`import Testing`). Tests never touch the network or the user's real vault (spec §11).
- All user-facing copy is **Simplified Chinese**, exactly as written in the spec; code, comments, identifiers and commit messages are English.
- Notes are shown by title only — **no per-note icons or emoji**. SF Symbols only for system-level elements, always with a text label except toolbar buttons (which need tooltip + accessibility label) (spec §1.2.3).
- Colors: system semantic colors only, no brand colors (spec §9.4). All `#available(macOS 26, *)` checks live only in `GlassStyle` (spec §9.1).
- No polling timers for file changes; FSEvents only (spec §3).
- Do not depend on Apple Intelligence / Foundation Models anywhere (spec §1.2.6).
- Text ranges exchanged between modules are `NSRange` in **UTF-16** units (what `NSTextView` uses).
- Resource budget (spec §3) is measured at the end of each milestone and appended to `docs/perf-log.md`.

## Review Focus

1. **Chinese IME composition** — restyling while `hasMarkedText()` is true breaks the candidate window and can corrupt input; expected: no restyle until composition ends. Test in Task 12.
2. **UTF-8 vs UTF-16 offsets** — swift-markdown reports columns as 1-based UTF-8 byte offsets; CJK and emoji text must still map to correct `NSRange`s. Test in Task 8.
3. **Text edited while an AI request is in flight** — the returned result must be discarded, never applied over newer text. Test in Task 26.
4. **Open note renamed or deleted outside the app** — its tab/pin must follow the rename or be removed cleanly, never point at a missing path silently. Test in Task 16.
5. **Non-UTF-8 or unreadable file in the vault** — the app must not crash or overwrite it; it is listed but opening shows an error banner, and it is never auto-saved. Tests in Tasks 3 and 6.
